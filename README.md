# Node.js Express Boilerplate (Replication)

This project is my attempt at replicating a Node.js + Express boilerplate provided to me.  
The goal is to better understand backend architecture, middleware patterns, and API structuring.

---

## Features

- Express.js server setup
- Modular routing structure
- Environment variable configuration

---

## Tech Stack

- Node.js
- Express.js
- dotenv

---

## Project Structure

```
src/
│── config/ # Database & environment configs
│── controllers/ # Route logic
│── routes/ # API routes
│── server.js # Entry point
```
